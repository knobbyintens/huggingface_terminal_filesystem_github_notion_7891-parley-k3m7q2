# Parley corpus kit

Working repository for the Parley conversation-benchmark families.

- Candidate family packages: `families/`
- Packaging rules: `families/README.md`
- Canonical rendering reference: `families/_example/data/expected_messages.jsonl`
- Release history and audit records: `releases/`
- Release tracker: `ops/release_status.json`

The 2026-11 release is being prepared. Release artefacts belong in `release/`.
